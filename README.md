> **PDFTool** is a modern suite of free, private, client-side PDF and image utility tools. All operations run directly in your browser using WebAssembly and client-side JavaScript — your confidential documents and images never touch a server.

---

## 🚀 Features & Tools

### 1. [PDF Compressor](https://pdftool4you.in/pdf-compressor.html)
- Compress large PDF files to exact target sizes (e.g. 100 KB, 200 KB, 500 KB, 1 MB).
- High visual quality with smart adaptive rendering.
- Real-time side-by-side preview with percentage compression ratio.

### 2. [Merge PDF](https://pdftool4you.in/merge-pdf.html)
- Combine multiple PDF documents into a single organized file.
- Drag-and-drop page reordering.
- Fast, instant merging without page count limits.

### 3. [Split PDF](https://pdftool4you.in/split-pdf.html)
- Extract individual pages or custom ranges (e.g., `1, 3-5, 8`).
- Burst all pages into separate downloadable PDFs.
- Clean visual thumbnail selection.

### 4. [PDF Watermarker](https://pdftool4you.in/pdf-watermarker.html)
- Add custom text watermarks ("CONFIDENTIAL", "DRAFT", custom text).
- Stamp company logos or signature images.
- Full control over opacity, angle, font, color, and positioning.

### 5. [Image to PDF](https://pdftool4you.in/image-to-pdf.html)
- Convert JPG, PNG, and WebP images into standardized PDF files.
- Adjustable margins and page orientation (portrait / landscape).

### 6. [PNG to JPG & JPG to PNG Converter](https://pdftool4you.in/png-to-jpg.html)
- Instant image format conversion with lossy/lossless compression slider.
- Zero server processing.

## 🔒 100% Privacy & Security Guarantee

Unlike traditional online PDF converters that require you to upload confidential tax documents, contracts, and IDs to remote cloud servers:
- **Zero Server Uploads:** 100% of processing happens in your device's memory.
- **Offline Capable:** Works without sending files across the internet.
- **Data Compliance:** Fully compliant with GDPR, CCPA, and strict organizational privacy requirements.
